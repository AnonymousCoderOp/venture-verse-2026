## 💡 Project Highlights
This project was built from scratch without external component libraries, focusing on modern UI/UX design and advanced CSS/JS techniques:

* **3D Flip-Clock Countdown:** Custom-built JavaScript interval timer with real-time 3D CSS tick animations.
* **Dynamic Theme Switcher:** Fully persistent Dark/Light mode toggle that instantly updates CSS variables and branding assets.
* **Scroll-Reveal Animations:** Multi-directional, cascading element reveals dynamically powered by the Intersection Observer API.
* **Immersive Hover Effects:** Custom card elevation, 3D scaling, and dynamic border lighting on the leadership grid.

---

## 🛠️ Tech Stack
* **HTML5:** Semantic structure and optimized asset loading.
* **CSS3:** Advanced Keyframes, Custom Variables, Flexbox, Grid, and 3D Transforms.
* **Vanilla JavaScript:** DOM manipulation, theme state management, and asynchronous observer logic.
